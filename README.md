# Kiro Código Facilito

Videojuego 3D creado para la hackatón de Código Facilito.

## Desarrollo local

```bash
cd biblioteca-perdida-de-codi
npm install
npm run dev
```

## Producción en Netlify

La configuración de `netlify.toml` instala y compila el proyecto Vite desde
`biblioteca-perdida-de-codi` y publica el contenido generado en `dist`.
